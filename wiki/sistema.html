O sistema

O BaseRoot Linux eh uma distribuicao minimalista x86_64 construida do zero com musl libc, toybox e mksh. O sistema utiliza o bootloader Limine com suporte a UEFI e BIOS, e o init system sinit, com scripts simples em /etc/init.d. O gerenciamento de pacotes eh feito pelo dumpkg (ou pelo spkg), incluidos na instalacao base.

Kernel

O kernel eh o Linux 6.1 LTS (versao 6.1.187), com o sufixo -baseroot. Ele sobe direto do disco, sem initramfs, e traz embutido o que eh preciso para iniciar: sistemas de arquivos (ext2/3/4, FAT, exFAT), controladores de disco (SATA, NVMe), tabelas GPT e MBR, UEFI com EFI stub, video (i915, bochs-drm, virtio-gpu, VGA e VESA) e USB tethering (CDC Ether, RNDIS, iPhone).

O resto vem como modulos no pacote linux-modules: Wi-Fi, placas de rede, entre outros. Os drivers de GPU Nouveau, AMDGPU e Radeon ficam desligados de proposito, para o kernel ser leve.

Para quem compila o proprio kernel e quer o mesmo comportamento:

  • CONFIG_FW_LOADER_COMPRESS=y e CONFIG_FW_LOADER_COMPRESS_ZSTD=y -- os firmwares ficam em .zst.
  • CONFIG_CFG80211_REQUIRE_SIGNED_REGDB=y -- o pacote wireless-regdb traz o banco assinado.
  • CONFIG_LOCALVERSION="-baseroot" -- amarra os modulos a este kernel.
  • Para o Firefox: namespaces (USER_NS, PID_NS, NET_NS, IPC_NS, UTS_NS), SECCOMP_FILTER, SYSVIPC e /dev/shm como tmpfs.
  • Para notebook: ACPI_BATTERY, ACPI_AC e ACPI_BUTTON como =y, pois nada carrega modulo sozinho.

Firmware

Os firmwares ficam em pacotes separados, um por familia de hardware, todos da versao linux-firmware 20261019. Instale so o do seu hardware -- descubra com lspci ou lsusb. Os arquivos vao para /lib/firmware e o kernel descomprime os .zst sozinho.

Inicializacao

O init chama /etc/init.d/rcS, que roda os scripts de servico em ordem numerica (por exemplo S11-udev, S16-dbus, S20-hostname, S32-wifi, S40-dropbear). A rede por cabo sobe sozinha com DHCP. Um servico roda no boot quando o script esta executavel: ligar ou desligar eh so um chmod, ou o comando service <nome> enable / disable.

O S32-wifi vem desligado (veja br-wifi). O Dropbear (servidor SSH, porta 22) tambem vem desligado: o Setup pergunta se voce quer ligar, ou depois use service dropbear enable. As contas precisam ter senha para conseguir entrar.
