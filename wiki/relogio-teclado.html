Relogio e teclado

Fuso horario e relogio

As opcoes ficam em /etc/default/clock:

TIMEZONE="America/Fortaleza"   # um nome de /usr/share/zoneinfo
HWCLOCK="utc"                  # "utc" ou "localtime"
NTP_SERVER="pool.ntp.org"      # vazio desliga o acerto pela internet

Para ver os fusos disponiveis:

find /usr/share/zoneinfo -type f

Depois de mudar o arquivo, aplique com service clock restart e confira com date. O instalador ja pergunta o fuso e grava esse arquivo no sistema novo.

Como a hora eh mantida

  • No boot, o servico clock le o relogio da placa (RTC) e aplica o fuso.
  • Ao desligar ou reiniciar, a hora do sistema eh gravada de volta na placa, para nao se perder.
  • Depois que a rede sobe, o servico ntp acerta a hora pela internet (sntp) e grava na placa. Ele tenta por cerca de dois minutos e para; o resultado fica no /var/log/boot.log.

Se o computador tambem roda Windows, use HWCLOCK="localtime": o Windows guarda a hora local no relogio da placa e os dois sistemas passam a concordar.

Acertar a mao

date -s "2026-10-24 20:30:00"     # acerta a hora do sistema
hwclock -w -u                     # grava na placa (use -l se for hora local)
sntp -s pool.ntp.org              # acerta pela internet

Teclado

O layout padrao eh o americano. Para testar um layout agora:

loadkeys br-abnt2

Para ficar fixo, edite /etc/default/keymap:

KEYMAP="br-abnt2"

E aplique com service keymap restart. O instalador tambem pergunta o layout e grava esse arquivo.

Para ver os layouts incluidos:

find /usr/share/keymaps -name "*.map"

Alguns nomes uteis: us, br-abnt2, br-latin1-abnt2, pt-latin1, es, fr, de, it, uk.

O layout vale para os terminais do console (as telas Alt+F1, F2, F3). Quem entra por SSH usa o teclado do proprio computador.
