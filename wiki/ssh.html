SSH

O BaseRoot inclui o Dropbear, um servidor SSH pequeno. Ele vem desligado por padrao.

Ligar

Antes, crie um usuario comum com senha (setup-users): o Dropbear nao aceita contas sem senha, e a conta root da iso nao tem.

service dropbear enable      # liga no boot
service dropbear start       # liga agora
service dropbear status

Conectar

De outro computador na mesma rede:

ssh usuario@endereco-do-baseroot

O endereco aparece em ip addr. No QEMU com rede padrao, encaminhe uma porta do seu computador para a porta 22 da maquina virtual:

qemu-system-x86_64 -m 512 -cdrom baseroot.iso -nic user,hostfwd=tcp::2222-:22
ssh -p 2222 usuario@localhost

Chaves do servidor

O Dropbear cria as chaves na primeira conexao, em /etc/dropbear. Na iso (que roda na memoria) elas sao geradas de novo a cada boot, e o ssh avisa que a chave mudou. Para testar sem esse aviso:

ssh -o UserKnownHostsFile=/dev/null -o StrictHostKeyChecking=no -p 2222 usuario@localhost

No sistema instalado as chaves ficam no disco e nao mudam.

Opcoes

Ficam em /etc/default/dropbear:

DROPBEAR_ARGS="-R"        # padrao: cria as chaves sozinho
DROPBEAR_ARGS="-R -w"     # proibe o login do root
DROPBEAR_ARGS="-R -w -s"  # proibe o root e so aceita chave (sem senha)

Depois de mudar, rode service dropbear restart. Cuidado: so use -w depois de ter um usuario comum, senao voce fica sem como entrar.

Entrar com chave

No computador de onde voce vai conectar, gere uma chave (ssh-keygen) e copie a parte publica para o BaseRoot:

mkdir -p ~/.ssh
vi ~/.ssh/authorized_keys     # cole a linha do arquivo .pub
chmod 700 ~/.ssh
chmod 600 ~/.ssh/authorized_keys

O Dropbear recusa a chave se a pasta pessoal, o .ssh ou o authorized_keys puderem ser alterados por outros usuarios.
