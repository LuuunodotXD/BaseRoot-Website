QEMU

O QEMU permite testar o BaseRoot sem mexer no seu computador. Os exemplos abaixo usam 512 MiB de RAM.

Boot por BIOS (padrao do QEMU)

qemu-system-x86_64 -m 512 -cdrom baseroot.iso

Boot por UEFI

Precisa do firmware OVMF (o caminho muda de acordo com a distribuicao):

qemu-system-x86_64 -m 512 -bios OVMF.fd -cdrom baseroot.iso -boot d

Mais rapido com KVM

Se o seu computador tiver virtualizacao, acrescente -enable-kvm. Sem ele o sistema roda, mas fica mais lento.

Com disco virtual (para testar a instalacao)

qemu-img create -f qcow2 disco.qcow2 8G
qemu-system-x86_64 -m 512 -cdrom baseroot.iso -hda disco.qcow2 -boot d

Rede

Por padrao o QEMU cria uma rede em modo usuario (NAT): o BaseRoot recebe um endereco por DHCP (algo como 10.0.2.15) e acessa a internet, mas o computador de fora nao alcanca a maquina virtual. Dois detalhes:

  • O ping nao funciona nesse modo (o QEMU nao repassa ICMP). Teste a rede com wget.
  • Para entrar na maquina virtual por SSH, encaminhe uma porta do seu computador para a porta 22:
qemu-system-x86_64 -m 512 -cdrom baseroot.iso -nic user,hostfwd=tcp::2222-:22

Depois, no seu computador: ssh -p 2222 usuario@localhost (antes, ligue o Dropbear no BaseRoot).
