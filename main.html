O Projeto BaseRoot Toybox/Linux

O BaseRoot Linux eh uma distribuicao linux x86_64 focada em minimalismo extremo, eficiencia e controle total do usuario. O sistema opera inteiramente atraves de uma interface de modo texto e linha de comando, sem initramfs pesados nem dependencias desnecessarias do espaco de usuario.

O projeto engloba nao apenas a distribuicao em si, mas tambem um ecossistema proprio de ferramentas desenvolvidas do zero:

  • BaseRoot Linux -- a distribuicao, construida com musl, toybox e mksh
  • dumpkg -- gerenciador de pacotes binarios baseado em receitas (.binfile)
  • spkg -- gerenciador de pacotes alternativo, ainda mais minimo, baseado em JSON
  • setup -- instalador TUI para instalacao em disco

Tudo escrito em shell POSIX puro, projetado para rodar em qualquer sistema minimo com toybox ou busybox.

BaseRoot Linux

O BaseRoot Linux eh uma distribuicao minimalista x86_64 construida do zero com musl libc, toybox e mksh. O sistema utiliza o bootloader Limine com suporte a UEFI, e o init system sinit. O gerenciamento de pacotes eh feito pelo dumpkg, incluido na instalacao base.

Componentes principais:

  • Kernel Linux 6.1 LTS (LTS) com drivers i915, bochs-drm e suporte a USB Tethering
  • musl libc 1.2.6
  • toybox 0.8.11
  • mksh como shell padrao
  • sinit como init system
  • LibreSSL + libretls para suporte a HTTPS
  • Dropbear para acesso SSH
  • Limine como bootloader (UEFI)
  • dumpkg como gerenciador de pacotes

DUMPKG

O dumpkg eh um gerenciador de pacotes binarios minimalista escrito em shell POSIX puro. Funciona atraves de receitas (.binfile) com informacoes do pacote, URL de download e checksum. Nao resolve dependencias automaticamente por padrao, mas oferece a flag -d para instalacao com dependencias.

Principais funcionalidades:

  • dumpkg-install <pkg> -- instala um ou mais pacotes
  • dumpkg-install -d <pkg> -- instala com dependencias
  • dumpkg-remove <pkg> -- remove um ou mais pacotes
  • dumpkg-update -- sincroniza receitas e atualiza pacotes
  • dumpkg list -- lista pacotes instalados
  • dumpkg search <pkg> -- pesquisa no repositorio
  • dumpkg deptree <pkg> -- exibe arvore de dependencias
  • dumpkg verify <pkg> -- verifica integridade dos arquivos

Codigo-fonte disponivel em: www.github.com/LuuunodotXD/Dump-Package-Manager


spkg

O spkg eh um gerenciador de pacotes alternativo e ainda mais simples, compativel com o shell do toybox. Usa um repositorio no formato JSON e nao depende de receitas -- apenas uma lista de pacotes com nome, versao e link de download.

Comandos:

  • spkg sync -- sincroniza o repositorio
  • spkg add <pkg> -- instala um ou mais pacotes
  • spkg del <pkg> -- remove um ou mais pacotes
  • spkg up -- atualiza todos os pacotes
  • spkg list -- lista pacotes instalados

Codigo-fonte disponivel em: www.github.com/LuuunodotXD/spkg


Setup

O setup eh o instalador TUI do BaseRoot Linux. Ele guia o usuario pelo processo de instalacao de forma simples e direta, sem particionar o disco -- o usuario monta as particoes manualmente antes de rodar o instalador.

O que o instalador faz:

  • Pergunta o ponto de montagem do sistema (/)
  • Pergunta se ha particao /home e swap separadas
  • Detecta automaticamente se o sistema usa UEFI ou BIOS
  • Extrai os grupos de pacotes selecionados pelo usuario
  • Configura o fstab e o limine.conf automaticamente
  • Instala o bootloader Limine na particao correta
